# bm-blocked

Локальный Windows-сервис для работы со списками запрещённых площадок активных кампаний РСЯ в Яндекс Директе. Сервис загружает клиентов, показывает заполнение лимита запрещённых площадок, проверяет доступность web-площадок и позволяет удалить подтверждённо неработающие адреса из выбранных кампаний с возможностью отменить последнее изменение. Отдельная проверка находит каналы по настраиваемым префиксам, периоду и порогу расхода, показывает предварительный результат с учётом лимита и добавляет выбранные площадки в запрещённые. Долгую проверку сайтов можно остановить с сохранением полностью полученных результатов. App-площадки распознаются и пропускаются без проверки. Новые версии автоматически скачиваются из официального GitHub-репозитория и устанавливаются после подтверждения пользователя, удаляя устаревшие программные файлы.

## Установка

1. Откройте раздел **Releases** на странице репозитория.
2. Скачайте `bm-blocked.zip` из последнего выпуска.
3. Полностью распакуйте архив в отдельную папку.
4. Запустите `bm-blocked.exe`.
5. Введите общий пароль компании.

Приложение откроет интерфейс в браузере и продолжит работать в системном трее. Для завершения используйте пункт **Выход** в меню значка трея.

Не переносите EXE отдельно от остальных файлов: рядом должны оставаться `server.js`, `index.html`, `auth-config.json` и папка `runtime`.

## Что потребуется

- Windows 10 или Windows 11;
- доступ в интернет;
- OAuth-токен Яндекс Директа;
- права на выбранный рекламный аккаунт;
- пароль компании для входа в сервис.
